# Audio Asset Examples

Sound and music controls are included in Settings, and the game ships with
small generated WAV files, including a 32-second sci-fi background loop, so it works immediately.

To add real audio later, place files here such as:

- `background_music.mp3`
- `crystal.wav`
- `explosion.wav`

The current audio files are:

- `space_loop.wav`
- `tap.wav`
- `crystal.wav`
- `explosion.wav`
- `game_over.wav`

You can replace these files with your own sounds later. Keep the same file
names if you do not want to edit `AudioService`.
