# Image Asset Examples

This game draws the spaceship, asteroids, crystals, stars, and explosions with
Flutter `CustomPainter`, so it does not require image files to run.

For a project fair upgrade, you can place files here such as:

- `ship.png`
- `asteroid.png`
- `crystal.png`
- `logo.png`

Then register and load them from `pubspec.yaml`.
